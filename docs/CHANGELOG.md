# Changelog

## 2.0 — 2026-10-09

- Replaced main entry interface with navy/cyan Flight Lab operation view, sticky essential status and desktop aircraft.
- Added quick passenger/bag boarding, station-selectable SVG, compartment transfers, CG/%MAC and mass-envelope plot.
- Added centralized fictional geometry, operational checks, runway/climb training model and deterministic fuel-budget flight manager.
- Added ten campaign missions, actual load verification, late load invalidation, early return/holding, route extension and alternate decisions.
- Added PLAY/LAB/LEARN, progress persistence with failure fallback, weighted score and achievement ranks.
- Added state-based debrief timeline and isolated departure what-if calculations.
- Preserved original Oxford PNGs, mass formulas and educational scripts unchanged; previous game remains at classic.html.
- Added source audit, model assumptions, mission branches, reproducible numerical/browser checks and documentation.
- Kept existing GitHub Pages path and main/root deployment mechanism. Original main preserved on pre-v2-redesign.

No accident trajectory, forced-landing, loss-of-control or damage simulation is claimed. No external runtime dependency, tracking service or account was added.
